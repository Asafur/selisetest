# Project Context

Last updated: 2026-05-02

## Product Goal

Build a SELISE-powered drag-and-drop website builder, similar in purpose to WordPress, Wix, or Webflow, but scoped as an MVP.

This is a real product direction, not a fake prototype. The app must let authenticated users create and manage websites, create pages, visually compose page layouts with drag-and-drop blocks, customize themes/templates, use SELISE-backed persistence, use SELISE media/storage if configured, and publish pages through the SELISE/Construct deployment model.

## Hard Rules

- Use SELISE Blocks only for backend/platform services.
- Do not create a custom backend.
- Do not create fake or mock APIs.
- Do not use mock data unless the user explicitly allows it later.
- Do not use localStorage as source of truth.
- Do not create local JSON files as source of truth.
- Use SELISE Data Gateway for persistence.
- Use SELISE Identity/Access Manager for authentication and roles.
- Use SELISE Storage/media only for uploads.
- If SELISE schemas/services are missing, stop and list exact manual SELISE setup requirements.
- Do not commit real `.env` values, Blocks keys, or secrets.
- Do not expose Blocks keys in docs, README, commits, final answers, or logs.
- Use official SELISE Blocks/Construct structure as the foundation.
- Do not depend on random third-party repos as the project source.

## MVP Scope

Required:

- Multi-site support if feasible from the start.
- Page creation and management.
- Drag-and-drop builder.
- Theme/template system.
- Authenticated admin panel.
- Basic owner/editor/viewer role model.
- Editable navbar/header and footer.
- Public page rendering with clean routes.
- Drafts hidden from public visitors.
- Contact form submissions saved through SELISE Data Gateway.
- Gallery/image/media usage only through SELISE Storage if configured.
- Global theme settings and per-page override if feasible.
- Undo/redo.
- Autosave.
- Publish confirmation.

Not required for MVP:

- Blog/posts.
- Plugin marketplace.
- SEO settings.
- Custom domains.
- Advanced marketplace system.
- Full pixel-perfect Webflow clone.

Because of the no-mock-data rule, the feature uses real SELISE service calls and shows blocked/error states when services or permissions are missing. It does not create fake Site/Page data.
